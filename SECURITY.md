# Security policy

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's vulnerability reporting](https://github.com/themesengine/software-engineer-portfolio-theme/security/advisories/new) and include the affected files or routes, the steps to reproduce and the likely impact.

The form endpoints and `server.mjs` are the most security-sensitive parts of the theme.
